We kindly request your expertise in describing microbial metagenomic samples.
You will be given one or more terms from the Environment Ontology (ENVO) or the Uber-anatomy Ontology (UBERON). Each term comes with its id, label, synonyms, definition and parent terms.

For each term, imagine the metadata of {n_examples} different microbial metagenomic samples whose origin would be annotated with this term, as its broad-scale environment, its local environment or its environmental material (whichever fits the term). Make the {n_examples} samples differ in a plausible way, for example different hosts, sites or contexts in which the term applies.

For each imagined sample, give what you would extract from its metadata:
    keywords: string // Five to eight keywords, descriptive of the sample origin, separated by commas. Put them within curly brackets.
    sub-biome: string // A brief, up to three-word description of the sample's specific origin. For 'animal' or 'plant' sources, please specify the host and part thereof. For 'water' samples, the type of water body is sought (e.g., lake, brine, sea, waste water, etc). If from 'soil', specify (e.g.: agricultural, desert, forest, etc). Otherwise specify which (e.g.: urban, laboratory, feed/food, fungus, air, etc).

Do not invent place names, countries, project names, dates or identifiers.

You will output a json object with one entry per input term, keyed by the term id exactly as given in the input:

{
    "<term-id>": [ {"keywords": string, "sub-biome": string}, ... ] // exactly {n_examples} imagined samples
}
